# EKANNTO Business OS V53.2 — Wallet + Receipt + QR + Logo Fixes

- Seller Wallet, Available Balance, Withdraw Request and Seller Earnings now use the same authoritative seller wallet balance.
- Admin seller manual balance additions remain seller-specific via `seller.walletBalance`.
- Dashboard wallet calculation ignores already-applied manual adjustments to prevent double counting.
- Product Details seller block shows shop name + follower count + Follow only; seller name/ID are not shown there.
- Seller logo upload now removes edge-connected white background while preserving the logo mark.
- Product/shop/seller logo displays use contained logo presentation with white-edge cleanup support.
- Withdrawal receipt uses the crisp Ekannto SVG brand, contained QR card, and robust withdrawal lookup.
- Receipt PDF/print keeps the full receipt inside the page bounds.
- Admin Transaction ID field is optional; blank approval auto-generates sequential `EK-TXID-01`, `EK-TXID-02`, etc. A manually entered unique TxnID is preserved.
- Withdrawal receipt shows the saved Transaction ID when available.
- PWA manifest keeps the final Ekannto app icon for Home Screen/install surfaces.

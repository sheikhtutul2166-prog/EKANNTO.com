Seller Salary

প্রতি Seller-এর বিক্রয়, rejected, refund, return এবং এখনো পরিশোধ না করা সম্ভাব্য পাওনা। Reject/return/refund হওয়া পণ্যের মূল্য payable salary-তে যোগ করা হয় না। Escrow নিয়ম অনুযায়ী delivery/completion নিশ্চিত না হলে টাকা payout-ready ধরা হবে না।

Prototype সতর্কতা: এই পেজ বর্তমান browser-local data থেকে হিসাব করে। Admin ও Seller আলাদা ডিভাইসে নির্ভরযোগ্যভাবে sync, escrow release বা real payment নিশ্চিত করতে Worker API + D1 ledger প্রয়োজন।

হিসাবের নিয়ম

  • Seller-এর নিজের পণ্যের order item-ই গণনা করা হবে।
  • Rejected product count product catalogue-এর rejected status থেকে গণনা হয়; rejected item-এর বিক্রয়মূল্য salary নয়।
  • Refunded/returned item salary থেকে বাদ থাকে।
  • Pending salary-তে শুধু delivered/completed order item, কমিশন বাদ দিয়ে, এবং আগে paid হিসেবে চিহ্নিত নয়—এমন item অন্তর্ভুক্ত হয়।
  • একই item-কে duplicate হিসেবে গণনা না করার জন্য order ID + item ID/name দিয়ে মিলানো হয়।
